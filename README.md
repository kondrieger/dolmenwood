# 🍄 Кузница персонажей Dolmenwood

Инструмент для игры по **Dolmenwood Player's Book** (Necrotic Gnome, версия 6 августа 2024): генератор
персонажей с честными бросками, ручной ввод уже готовых, живой лист с автосохранением и перенос в
игровой VTT-лист. Всё на русском, игровые термины продублированы английскими из книги.

## Запуск

Нужна Node 22 или новее (на 20.11 ломается CLI Nuxt).

```bash
npm install
npm run dev
```

Откроется на `http://localhost:3000`. Первый запуск — только `npm install`, дальше сразу `npm run dev`.

## Что умеет

**Генератор.** Выбираешь род и класс, жмёшь кнопку — получаешь готового персонажа 1 уровня по всем
тринадцати шагам создания из книги: характеристики, хиты, КБ, спасброски, навыки, языки, снаряжение,
магия, безделушка, внешность, прошлое, лунный знак. Каждый бросок показывается кубиком нужной
размерности (d4, d6, d8, d10, d12, d20, d100).

Поддержаны обе схемы книги: **род + класс** (6 родов × 9 классов со всеми ограничениями) и
**род-класс** из приложения, стр. 180+ (бреггл, эльф, гримолкин, мослинг, вудгрю).

**Ручной ввод.** Для персонажей, созданных за столом или на другом сайте — без кубиков, любого уровня.
Заполняешь характеристики, хиты, магию и внешность; атака, спасброски, цели навыков, пороги опыта,
КБ и вес считаются сами по таблицам книги. Нарушения правил не блокируются молча, а показываются
списком: что не сходится и на какой странице это написано.

**Лист персонажа.** Раскладка и названия полей те же, что на игровом VTT (Stats, Inventory, Magic,
Traits, Extra Details, Notes). Всё, что можно править, правится прямо в листе и сразу пишется в файл.
Что выводится правилами — показано серым и пересчитывается само.

**Каталог предметов.** Всё снаряжение книги с поиском и фильтром. Предмет добавляется в руки или в
рюкзак, вес и скорость пересчитываются мгновенно. Если класс не может носить эту броню или оружие
такого размера — покажет предупреждение, но решать тебе и Рефери.

**Повышение уровня.** Мастер ведёт по шагам из книги (стр. 25): бросок хитов, новые атака и
спасброски, заклинания и навыки, а дальше — всё, что положено конкретному персонажу: боевой талант
воина, гламуры, бросок 2d6 на дар руны фей, симбиотическая плоть мослинга, святой орден клирика,
ступени сноровки, посвящение рыцаря. Каждый бросок пишется в журнал.

**Честность.** Броски идут через `crypto.getRandomValues` с отбраковкой, чтобы не было смещения по
модулю. Каждый бросок попадает в журнал: что бросали, что выпало, что из этого вышло. Журнал и
контрольная сумма уходят в JSON — гейм-мастер видит, что ничего не подкручено.

**Шпаргалка и справочник.** Персональный раздел «как этим играть» на странице каждого персонажа плюс
общий справочник с таблицами. Термины подчёркнуты пунктиром — при наведении всплывает объяснение со
ссылкой на страницу книги.

**Промпт для портрета.** Собирается под конкретного персонажа — на английском и по-русски: внешность
рода из книги, облик класса или род-класса, все выпавшие приметы, длина рогов бреггла по фактическому
уровню, симбиотическая плоть мослинга, гламуры и сноровки, безделушка, прошлое, лунный знак и
настоящее носимое снаряжение. Меняешь лист — меняется и промпт. Палитра, свет и композиция берутся
детерминированно из идентификатора: один герой всегда даёт один и тот же промпт, а два разных
мослинга-воина выглядят по-разному. Наборы оформления свои у смертных, фей и полуфейских.

## Хранение

Каждый персонаж — отдельный файл `characters/<id>.json`. Файл можно открыть, положить в бэкап,
переслать гейм-мастеру или править руками. Правки в листе сохраняются автоматически.

**Персонажи намеренно лежат под контролем версий.** Это единственная страховка от потери листа:
удалённый файл, который git не отслеживал, восстановить неоткуда. Коммить после сессии — заодно
получится история персонажа.

## Домашние правила нашей игры

- **Нагрузка по весу** в монетах (10 монет = 1 фунт), стр. 148: до 400 → Скорость 40, до 600 → 30,
  до 800 → 20, до 1600 → 10. Больше 1600 не унести.
- **Одежда и поясной кошель не считаются** ни в инвентаре, ни в весе.
- Монеты весят по 1 и в вес входят.

Правила собраны в `data/equipment.js` (`WEIGHT_ENCUMBRANCE`, `LOAD_EXEMPT_IDS`, `LOAD_EXEMPT_CATS`).

## Как устроено

Nuxt 3 в SPA-режиме, серверные роуты Nitro для файлового хранилища.

```
data/               таблицы книги: роды, классы, магия, снаряжение, календарь, глоссарий
utils/              честный ГСЧ, генератор, ручной ввод, пересчёт листа, промпт портрета
composables/        каталог персонажей и настройки
server/api/         чтение и запись characters/*.json
pages/              генератор, ручной ввод, каталог, лист персонажа, справочник
components/         лист в раскладке VTT, каталог предметов, мастер уровня, шпаргалка, кубики
characters/         сами персонажи, по файлу на каждого
```

Данные и логика разделены: чтобы поправить таблицу из книги, лезть в код не нужно.

Папки `js/`, `css/` и `index.html` остались от первой, ванильной версии и больше не используются —
их можно удалить.
